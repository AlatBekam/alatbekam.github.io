## Overview

A collection of CSS layout exercises from WPU (Web Programming UNPAS) course, focusing on Flexbox and Grid.

## Topics Covered

- CSS Flexbox: `display: flex`, `justify-content`, `align-items`, `flex-wrap`
- CSS Grid: `grid-template-columns`, `grid-template-rows`, `gap`
- Responsive layouts using both systems
- When to use Flexbox vs Grid

## Tech Stack

- HTML5
- CSS3

## Key Takeaways

- Flexbox is great for 1D layouts (rows or columns)
- Grid excels at 2D layouts (rows and columns simultaneously)
- Combining both gives maximum flexibility
