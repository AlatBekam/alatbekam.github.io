## Overview

An experiment with the TiltJS library to create interactive 3D tilt effects on card elements.

## Features

- 3D perspective transforms
- Smooth mouse-tracking animations
- Glare effect overlay
- Configurable tilt angles

## Tech Stack

- HTML5
- CSS3
- TiltJS library

## What I Learned

- Understanding CSS 3D transforms
- Mouse event handling for interactive effects
- Library integration patterns
