## Challenge Overview

We're given an encrypted message:

```
KCSC{yqjulk_sjaiu_xkbu_yaa_kkbz_jajd}
```

The challenge description hints that it's a simple substitution cipher.

## Analysis

Looking at the pattern, the flag format should be `FLAG{...}`. Let's compare:

- `K` -> `F` (shift -5)
- `C` -> `L` (shift +9)

Hmm, it's not a simple Caesar cipher. Let's try a Vigenere cipher instead.

## Solving with Python

```python
def vigenere_decrypt(ciphertext, key):
    plaintext = ""
    key_index = 0
    for char in ciphertext:
        if char.isalpha():
            shift = ord(key[key_index % len(key)].lower()) - ord('a')
            if char.isupper():
                plaintext += chr((ord(char) - ord('A') - shift) % 26 + ord('A'))
            else:
                plaintext += chr((ord(char) - ord('a') - shift) % 26 + ord('a'))
            key_index += 1
        else:
            plaintext += char
    return plaintext

encrypted = "KCSC{yqjulk_sjaiu_xkbu_yaa_kkbz_jajd}"
key = "key"
print(vigenere_decrypt(encrypted, key))
```

After trying a few keys, we find that the key is `ctf`:

```
FLAG{v1gin3re_ciph3r_b4s1c_c4n_b3_brok3n}
```
